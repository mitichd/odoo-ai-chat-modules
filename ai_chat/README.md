# AI Chat для Odoo

AI-чат модуль для управління завданнями в Odoo.

## Функціональність
- 💬 Чат-віджет у правому нижньому куті
- 👥 Ролі, права для PM та Developer
- 🤖 Парсер команд (12)
- 📋 Управління завданнями

## Реалізовано
- ✅ Базова структура модуля
- ✅ Чат-віджет з формою
- ✅ Парсер команд з валідацією
- ✅ Контролер для обробки повідомлень
- ✅ Прокрутка в чаті

## Запуск
```bash
python odoo-bin --addons-path=addons,custom_addons -d ai_chat_test
```
